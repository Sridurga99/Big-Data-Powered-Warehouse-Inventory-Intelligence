# Big Data Powered Warehouse Inventory Intelligence

## Member 1: Big Data and Data Engineering Pipeline

### Objective

The Big Data module processes warehouse data using Hadoop HDFS, MapReduce, and Hive to produce clean and aggregated datasets for the downstream demand forecasting and inventory intelligence modules.

- Hadoop MapReduce
- Hive
- YARN
- Python

## HDFS Data Organization

The warehouse data is stored in HDFS under:

`/warehouse_inventory/`

The major datasets are:

- Sales
- Inventory
- Products
- Suppliers
- Warehouses
- External Events

## MapReduce Processing

The MapReduce module processes sales data by product.

### Mapper

The mapper extracts:

`product_id -> quantity`

### Reducer

The reducer calculates the total quantity sold for each product.

Verified output:

| Product ID | Total Quantity |
|------------|----------------|
| P101 | 550 |
| P102 | 268 |

## Hive Processing

Hive provides structured access to the warehouse datasets.

The following external tables are created:

- sales
- inventory
- products
- suppliers
- warehouses
- external_events

Hive is also used to join sales and product information and generate product-level aggregated sales.

## Processed Outputs

The following files are provided to the downstream ML module:

### sales_clean.csv

Contains daily sales records and preserves the time-series structure required for demand forecasting.

### sales_by_product.csv

Contains product-level aggregated sales totals.

### sales_by_product.txt

Contains the raw output generated by the Hadoop MapReduce job.

## Downstream Handoff

The processed datasets are handed over to the ML module for:

- Demand forecasting
- Dynamic safety stock calculation
- Supplier lead-time consideration
- Reorder point calculation
- Inventory risk analysis
- Reorder recommendations

The Big Data module does not perform these downstream ML and inventory intelligence calculations.
